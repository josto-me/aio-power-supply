# Measurement: input current vs. output voltage

Bench test of the V2 board. The LED current is set to full scale; the output voltage is varied with the load. The output current is recorded in the first row only (3.3 A); all rows use the same full-scale current setting. The input voltage is not recorded, so no efficiency can be derived from this table.

| U_out (V) | I_in (A) | I_out (A) |
|---:|---:|---:|
| 0.744 | 1.1 | 3.3 |
| 5 | 1.7 | |
| 8.5 | 2.6 | |
| 10 | 3.2 | |
| 16 | 5.2 | |
| 20 | 6.8 | |
| 25 | 8.8 | |
| 30 | 9.6 | |

The measured 3.3 A agrees with the calculated full-scale LED current of 100 mV / 30 mΩ = 3.33 A (see README).
